## New Features

- Logged-in visitor destination: users who are signed in but lack access can be sent to a page such as a membership plans page instead of the login page.
- The `wpaag_user_can_access` filter now runs for anonymous visitors too, with a user ID of 0.
- Automated PHPUnit coverage for the access rules, run in CI on PHP 8.0, 8.2, and 8.4.

## Improvements

- The settings page warns that the default mode admits any active ARMember account, and warns again when open registration is enabled.
- Redirects build the correct return URL on subdirectory installs.
- Adverts and advert categories are left out of the XML sitemap for unauthorized visitors.
- Smaller release package.

## Bug Fixes

- Fixed a bypass where `?post_type[]=advert` archives and feeds listed adverts to logged-out visitors.
- Fixed a bypass where mixed-case REST routes such as `/wp-json/wp/v2/ADVERT` returned adverts to logged-out visitors.
- The default access mode now requires an active ARMember account. Inactive, pending, and terminated accounts were previously admitted.
- Single REST media items and comments attached to adverts are denied, and advert attachments and comments are removed from REST collections.
- Attachment pages of advert images are protected like the advert itself.
- oEmbed requests for adverts now return 401 instead of 404.
- WPAdverts forms ignore submitted advert IDs the user does not own.

## Upgrade Notes

- The hardcoded `login-2` default destination page is gone. If you never saved the plugin settings, open Settings > WP Adverts <> ARMember and choose the unauthorized visitor destination, or visitors will go to the WordPress login page.
- ARMember registers every WordPress user as an active member. To restrict classifieds to members with a plan, choose "Active ARMember account with a valid plan".
