## New Features

- Added ARMember-aware protection for WPAdverts single listings, archives, category pages, blocks, shortcodes, publishing and management pages, and advert REST routes.
- Added a configurable access mode for recognized ARMember users or active members with an effective plan.
- Added a WordPress page selector for the unauthorized-visitor destination.

## Improvements

- Added administrator bypass behavior so site management remains available when ARMember is unavailable.
- Added branded settings UI, GitHub repository metadata, Git Updater metadata, plugin action links, and project documentation.

## Bug Fixes

- Prevented unauthenticated advert data from remaining available through the WordPress REST API.
- Preserved the original requested URL in the destination page's `redirect_to` parameter.
