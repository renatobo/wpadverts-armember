## Security

- Closed REST access-control bypasses. oEmbed requests for an advert, `/wp/v2/search` with an `advert` subtype, and `/wp/v2/media` and `/wp/v2/comments` queries scoped to an advert now return HTTP 401 for unauthorized visitors. Protected routes are resolved by post type instead of a fixed route-prefix list.
- Removed adverts from frontend and REST search results for unauthorized visitors. `advert` is a public post type, so a plain `/?s=term` query previously exposed advert titles and excerpts without touching a protected surface.
- Blanked WPAdverts blocks and shortcodes wherever they render. The previous check scanned only `post_content`, so blocks and shortcodes placed in block-theme templates, template parts, synced patterns, or widgets were served to everyone.
- Denied WPAdverts admin-ajax actions to unauthorized visitors. `adverts_show_contact`, the contact form endpoint, and the gallery endpoints are registered for logged-out users and bypassed every access check.
- URL-encoded the `redirect_to` value on login redirects.

## Improvements

- Blocked classifieds render a member-only notice in place of their content.
- Access decisions are memoized per request, since they are now evaluated on every block render and search query.
- Protected block, shortcode, and admin-ajax action names are shared constants, so detection and enforcement cannot drift apart.

## Requirements

- Minimum WordPress version raised to 7.0 and minimum PHP version raised to 8.0.
- Declared `Requires Plugins: wpadverts, armember-membership`, so WordPress lists both dependencies on the plugins screen and blocks activation until they are active. Plugin dependencies match by folder slug, so sites running ARMember premium (the `armember` folder) must remove the `armember-membership` entry from the plugin header and `readme.txt`.
