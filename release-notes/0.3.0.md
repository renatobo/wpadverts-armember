## New Features

- Added automatic synchronization of WPAdverts contact name and email from the advert owner's ARMember-associated WordPress account.
- Added settings for using the account display name or first and last name.

## Improvements

- Made Contact Person and Email visible but read-only on frontend New Advert and Manage Advert forms.
- Preserved the metadata required by WPAdverts contact forms, notifications, and payment integrations.
- Existing adverts resolve their post author before synchronization, preventing administrator edits from taking ownership of contact details.

## Bug Fixes

- Prevented modified read-only form values from overriding profile-derived contact information.
